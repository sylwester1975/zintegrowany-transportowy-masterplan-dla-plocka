# zintegrowany-transportowy-masterplan-dla-plocka
Koncepcja strategiczna rozwoju układu transportowego aglomeracji płockiej jako krytycznego komponentu bezpieczeństwa paliwowo-energetycznego i obronnego RP. Eliminacja ryzyka „pojedynczego punktu awarii” – <em>Single Point of Failure</em> (SPoF).
Pełna wersja online z mapami: [Masterplan dla Płocka](https://masterplan-dla-plocka.netlify.app/)
